Session 18: AWS Services Research

Visual evidence of the Task 2 research deliverable. Detailed explanations are in the five README files.

IAM - Governance

  • Users, groups, roles, policies, and permissions
  • Least privilege, MFA, credential rotation, and access reviews
  • Used for human and workload authorization

EC2 - Compute

  • AMI, instance type, key pair, security group, and EBS
  • Public versus private IP addresses
  • Used for servers, runners, and workloads

S3 - Storage

  • Buckets and objects with storage classes
  • Versioning, lifecycle, encryption, and bucket policies
  • Used for artifacts, backups, logs, and data lakes

VPC - Networking

  • CIDR, subnets, route tables, Internet Gateway, NAT Gateway
  • Security Groups and Network ACLs
  • Public workloads separated from private workloads

DynamoDB and RDS - Databases

  • DynamoDB: NoSQL tables, items, attributes, partition/sort keys
  • RDS: managed relational engines, backups, Multi-AZ, replicas
  • Choose according to access patterns and data relationships
Prepared locally for the DevOps assignment; no AWS account or resources are required for this research task.
