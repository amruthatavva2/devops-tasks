# EC2 — Compute

EC2 is on-demand virtual compute. An **AMI** is the machine image; **instance types** define CPU/memory/networking; **key pairs** support SSH; **Security Groups** are stateful firewalls; **EBS** provides block storage. Public IPs are internet-routable through an Internet Gateway; private IPs stay inside a VPC. Lifecycle: pending → running → stopping/stopped or terminated. Uses include web servers, build runners, and legacy applications.
