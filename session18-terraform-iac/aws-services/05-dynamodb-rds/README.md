# DynamoDB and RDS

**DynamoDB** is a managed NoSQL database with tables, items, and attributes. A partition key distributes data; an optional sort key orders items within a partition. Uses: sessions, carts, high-scale key/value data.

**RDS** is managed relational database service supporting engines such as PostgreSQL, MySQL, MariaDB, Oracle, and SQL Server. DB instances run in private subnets with Security Groups, backups, encryption, Multi-AZ for high availability, and read replicas for scaling reads. Uses: transactional application data and relational reporting.
